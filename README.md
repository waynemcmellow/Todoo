#  Football To-Do List

##  About the Project
The Football To-Do List is a simple web application designed to help football players, teams, and coaches organize football-related tasks and activities. It allows users to keep track of tasks, manage responsibilities, and stay organized during training, matches, and team activities.

##  Features
- Add Tasks: Create new football-related tasks.
- Task Management: Keep track of tasks that need to be completed.
- Mark as Completed: Mark tasks as done.
- Delete Tasks: Remove tasks that are no longer needed.
- Simple Interface: Easy-to-use interface for managing daily activities.

##  Technologies Used

- CSS
- JavaScript

##  How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/waynemcmellow/Todoo
   

2. Open the project folder:
   
   cd football-todo-list
   

3. Open `index.html` in your browser.

##  Project Objective
The goal of this project is to provide a simple and practical way of organizing football tasks, helping users stay focused, manage their responsibilities, and complete activities on time.
